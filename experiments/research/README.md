# Autonomous research command centre

1. [Program](program.md): bounded, falsifiable iteration loop with data/evaluation firewall.
2. [Registry](registry.md): candidate lifecycle, including fallback champion.
3. [Decisions](decisions.md): audit trail, negative outcomes and scientific caveats.
4. [Experiments](../README.md): model portfolio, hypotheses, cards and evidence types.

Start every research batch with the hypothesis and evidence protocol; **do not** optimise the public five-minute labels. The final purpose is strongest plausible hidden spellF1 and a deterministic valid submission, not number of experiments.
